# Korp & Koppar

Projektarbete i kursen Introduktion till webbutveckling med HTML,
CSS och JavaScript (DT224G) vid Mittuniversitetet, HT2026.

Webbplatsen presenterar den fiktiva verksamheten Korp & Koppar som kombinerar café, butik och pysselträffar.

Målsättningen är betyg A-B. Jag tar gärna emot återkoppling på vad som uppfyller kriterierna och vad jag behöver utveckla vidare för att nå den nivån.

## Publicerad webbplats

https://kramzo.github.io/Projektarbetet/

## Sidor

- Hem: introduktion till verksamheten och genvägar till övrigt innehåll.
- Fika & butik: öppettider, fikameny och information om butiken.
- Pyssel & träffar: information om aktiviteter och priser.
- Kontakt: fiktiv adress, vägbeskrivning och kontaktformulär.

## Teknik och funktioner

Webbplatsen är byggd med HTML, CSS och JavaScript.

- Responsiv layout med Flexbox, CSS Grid och media queries.
- Mobilmeny som öppnas och stängs med JavaScript.
- Formulärvalidering med felmeddelanden.
- Dynamisk fikameny som skapas från en array med objekt.

Kontaktformuläret demonstrerar endast validering. Det skickar inte
meddelanden till någon mottagare.
